# 음악 플레이어

내 컴퓨터의 오디오 파일로 재생목록을 만들어 음악을 듣습니다.

- ID: `dockit.music-player`
- 작성자: nokryong

## 사용 방법

제목의 **오디오 파일 추가**로 파일을 고르면 재생목록에 들어갑니다. 재생·일시정지, 이전·다음 곡, 재생 위치 이동, 음량, 반복을 조절할 수 있습니다.

## 데이터와 권한

| 권한 | 용도 |
|---|---|
| `storage` | 음량 같은 재생 설정을 저장합니다. |

음악 파일은 업로드하거나 저장하지 않습니다. 선택한 파일은 현재 창에서만 재생하며, 툴킷을 닫거나 앱을 다시 열면 재생목록이 비워집니다. 외부와 통신하지 않습니다.

## 제한

브라우저나 앱이 지원하는 오디오 형식만 재생할 수 있습니다.
