# PRISM 연구보고서

정책연구관리시스템(PRISM)의 정책연구 과제를 검색하고 개요를 확인합니다.

- ID: `dockit.prism`
- 작성자: nokryong

## 사용 방법

검색 기준(과제명·기관명·연구자명)을 고르고 검색어를 입력한 뒤 **검색**을 누르거나 Enter를 누릅니다. 결과를 누르면 연구 개요를 보여 주고, 원문 페이지를 PRISM 사이트에서 열 수 있습니다.

## 통신과 권한

| 권한 | 용도 |
|---|---|
| `network` | `https://dockit.kr/api/prism`으로 검색과 상세 정보를 조회합니다. |
| `external` | 보고서 원문 페이지(`https://www.prism.go.kr`)를 기본 브라우저로 엽니다. |

API Key가 필요 없습니다. 플러그인 데이터는 저장하지 않습니다.

## 제한

플러그인은 JSON 응답만 받을 수 있어서 PDF를 직접 내려받거나 미리 보지 않습니다. 원문은 PRISM 사이트에서 확인합니다.
