# 주사위

[English](README.md) · 한국어

주사위를 추가하고 눌러서 굴립니다.

- ID: `dockit.dice`
- 작성자: nokryong

## 사용 방법

제목의 **주사위 추가**로 주사위를 늘리고, 주사위를 누르면 굴러갑니다.

## 데이터와 권한

| 권한 | 용도 |
|---|---|
| `storage` | 주사위 개수를 저장합니다. |

- Dockit Open: `.dockit/plugin-data/dockit.dice/storage.json`에 저장합니다.
- Dockit Web: 로그인하면 계정에 동기화되고, 로그인하지 않으면 현재 브라우저에만 저장합니다.

외부와 통신하지 않습니다.
